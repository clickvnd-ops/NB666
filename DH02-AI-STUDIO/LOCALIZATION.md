# Vietnamese localization

Updated visible plugin content: 185 opponent names, 48 biographies, 54 life descriptions, 21 weapons, 8 author pages, menu titles, locked-state labels, completion labels and mini-game instructions. Vietnamese name-input character pages preserve the 90-cell layout. System settings, combat feedback, save/load labels and engine errors are localized. Technical plugin keys, commands and asset paths are preserved.

29 image assets localized using image editing, including normal and pressed button states, loading screen, author-gallery headers and seven puzzle paintings. All images retain the original sprite dimensions and transparency where applicable. Paintings with illegible inscriptions use descriptive Vietnamese captions rather than claimed literal translations. Very small incidental text inside photographed packaging may remain; no claim of a pixel-exhaustive OCR pass.

Validation: modified JavaScript syntax checked; runtime JSON parsed; 570 plugin values updated and technical configuration compared with previous release, allowing only intended text/layout changes. All 29 image dimensions verified against prior release. No full gameplay walkthrough performed for this localization release.
